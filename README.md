# Zombie Apocalypse in Atharva University (VR)

Team: VOID R3APERS
Category: Game Development (PS-01: GlitchVerse)

A single-player VR zombie survival game for Meta Quest 3, built in Unity 6.
The player enters a portal at the university entrance, collects weapons from
an armory table, and fights waves of zombies and a final boss.
